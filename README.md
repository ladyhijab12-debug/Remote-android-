# ريموت التلفزيون — Android TV و Samsung

تطبيق أندرويد للجوال يتحكم عبر الواي فاي في:
- تلفزيونات **Android TV / Google TV** (سوني، TCL، شاومي، فيليبس، …) بنفس بروتوكول ريموت Google الرسمي.
- تلفزيونات **Samsung** الذكية (Tizen، موديلات 2016 وأحدث).

ما يحتاج وضع المطوّر ولا ADB.

## المميزات
- يلقى التلفزيونات على نفس الشبكة تلقائياً (mDNS)، أو تكتب عنوان IP يدوياً.
- الاقتران مرة وحدة برمز من 6 خانات يظهر على شاشة التلفزيون، وبعدها يتصل التطبيق تلقائياً.
- الأزرار: تشغيل/إطفاء، الأسهم و OK، رجوع، الرئيسية، القائمة، الصوت وكتم الصوت، القنوات، المصدر، الإعدادات، تشغيل/إيقاف مؤقت، ترجيع وتقديم.
- الضغط المطوّل على أي زر يبقيه مضغوط على التلفزيون (للتمرير أو التقديم السريع).
- أزرار الصوت في الجوال تتحكم في صوت التلفزيون وأنت فاتح الريموت.
- اختصارات لفتح YouTube و Netflix.
- الواجهة بالعربي.

## طريقة الاستخدام
1. خلّ الجوال والتلفزيون على نفس شبكة الواي فاي.
2. افتح التطبيق واختر التلفزيون من القائمة (أو اكتب IP التلفزيون).
3. أول مرة:
   - **Android TV:** بيظهر رمز على التلفزيون، اكتبه في التطبيق واضغط «اقتران».
   - **Samsung:** بيطلع طلب على شاشة التلفزيون، اضغط «سماح» بالريموت الأصلي.
4. خلاص، الريموت جاهز.

## سباحتي — تطبيق السباحة للساعة (Galaxy Watch Ultra / Wear OS)

الموديول `wear/` تطبيق مستقل للساعة كيتبع حصة السباحة فالمسبح.

**شنو كيعطيك:**
- المسافة (عدد الأطوال × طول المسبح)، الوقت بلا فترات الإيقاف، عدد الأطوال.
- المعدل لكل 100م، وقت آخر طول وأسرع طول.
- عدد الضربات و SWOLF (ثواني الطول + ضرباته) لكل طول، والنبض (الحالي، المتوسط، الأقصى) والسعرات — إلا كانت الساعة كتعطيهم للتطبيقات.
- تقرير كامل فآخر الحصة فيه جدول كل طول، وسجل لآخر 30 حصة.

**مواصفات على طريقة Garmin:**
- **المجموعات (Intervals) ومؤقت الراحة:** زر «راحة» عند الحائط كيسالي المجموعة وكيبدا عدّاد الراحة، و«انطلاق» كيبدا مجموعة جديدة. التقرير فيه مسافة ووقت ومعدل وراحة كل مجموعة.
- **وقت السباحة مفصول على وقت الراحة**، والمعدل / 100م كيتحسب على وقت السباحة فقط.
- **معدل الضربات** (ضربة / دقيقة) و**المسافة لكل ضربة** (متر / ضربة) لكل طول وبالمتوسط.
- **تنبيه المسافة:** اهتزاز ثلاثي كل 100 / 200 / 400 / 500 / 1000م (كتختاريه قبل البدء).
- **الزر الجانبي بحال زر LAP:** فالوضع التلقائي ضغطة = راحة / انطلاق؛ فالعدّ اليدوي ضغطة = طول، وضغطة طويلة = راحة (وكتحسب الطول اللي سالا).
- **قفل اللمس فالماء** (اختياري): أثناء السباحة اللمسات العادية ما كتدير والو؛ كتخدم غير الضغطة الطويلة على «راحة» والزر الجانبي. عند الحائط اللمس كيرجع عادي.
- ضغطتين متتابعتين فأقل من 5 ثواني كيتحسبو طول واحد، وآخر طول ما كيضيعش عند الإنهاء.
- **تسجيل التمارين (Drill log):** زر «تمرين» كيبدا عدّاد التمرين (رجلين، ذراع واحدة…)، ومن بعد «إيقاف التمرين» كتدخّلي المسافة بـ − و + وكتحفظيها. التمرين كيتحسب فالمسافة والوقت بلا ضربات ولا SWOLF، وكيبان فالتقرير كمجموعة «تمرين».
- **اختبار CSS (السرعة الحرجة):** من شاشة البداية «اختبار CSS» ← 400م بأقصى جهد ثابت ← راحة 10 دقائق ← 200م. الساعة كتوقف كل سباحة بوحدها عند 400م و200م، وفالآخر كتعطيك وتيرة CSS لكل 100م مع وتيرة التحمل (Z2) و VO2max (Z4). آخر نتيجة كتبقى مكتوبة فزر الاختبار.
- ما كاينش: التعرف التلقائي على نوع السباحة (حرة / صدر…) والراحة التلقائية — الساعة ما كتعطيش هاد المعلومات للتطبيقات الخارجية.

**كيفاش كيحسب الأطوال:**
- إلا كان وضع «سباحة المسبح» ديال Health Services متوفر فالساعة، الأطوال كتتحسب تلقائياً من حساسات الساعة.
- إلا ما كانش متوفر، التطبيق كيرجع للعدّ اليدوي: عند كل حائط اضغط «+ طول» أو أي زر جانبي فالساعة (الأزرار كتخدم والشاشة مبلولة). «حذف آخر طول» كيصحح أي غلط.
- الشاشة كتكتب ليك لتحت أي وضع خدام.

**الاستعمال:** اختار طول المسبح (25 / 50 أو عدّلو بـ − و +) ← «ابدأ السباحة» ← فالآخر ضغطة طويلة على «إنهاء».

**التثبيت:** حمّل `Swim-Watch.apk` من Actions ← Build APK ← Artifacts ← `SwimWatch-apk`، ومن بعد:
1. فالساعة: الإعدادات ← حول الساعة ← معلومات البرنامج ← اضغط 7 مرات على «إصدار البرنامج»، ثم خيارات المطوّر ← فعّل «تصحيح ADB» و«التصحيح اللاسلكي».
2. من الكمبيوتر: `adb pair IP:PORT` ثم `adb connect IP:PORT` ثم `adb install Swim-Watch.apk` (أو من الجوال بتطبيق بحال Bugjaeger).

> التطبيق مبني ومختبر المنطق ديالو بالاختبارات، لكن ما تجربش بعد على ساعة حقيقية فالماء.

## تحميل الـ APK
كل push للمستودع يبني APK تلقائياً عن طريق GitHub Actions:
**Actions ← Build APK ← آخر تشغيل ← Artifacts ← AndroidTvRemote-apk**.
فك الضغط وثبّت `app-debug.apk` على الجوال (لازم تسمح بالتثبيت من مصادر غير معروفة).

## البناء محلياً
```
./gradlew assembleDebug        # APK في app/build/outputs/apk/debug/
./gradlew testDebugUnitTest    # اختبارات البروتوكول ضد تلفزيون وهمي
```
يحتاج JDK 17 و Android SDK (أو افتح المشروع في Android Studio).

## How it works (English)
- `protocol/PairingClient.kt` — pairing on TCP 6467 over TLS with a self-signed client certificate; the TV shows a 6-hex-digit code and the secret is `SHA-256(client modulus, client exponent, server modulus, server exponent, code[2:])`.
- `protocol/RemoteClient.kt` — remote channel on TCP 6466: answers the TV's configure / set-active / ping messages and sends key presses and app links.
- `protocol/Proto.kt` — tiny hand-written protobuf encoder/decoder (no protobuf toolchain needed).
- `protocol/CertificateManager.kt` — generates the client certificate once (BouncyCastle) and keeps it in app storage, so the TV stays paired.
- `protocol/SamsungClient.kt` — Samsung Tizen WebSocket API (wss 8002, falls back to ws 8001); the TV asks the user to allow the app once and returns a token that is saved for later. Samsung TVs are discovered with SSDP.
- `wear/` — Wear OS swim tracker: `SwimSession.kt` (pure distance / pace / SWOLF maths, unit tested), `SwimService.kt` (Health Services `SWIMMING_POOL` exercise with a manual-count fallback), `SwimActivity.kt` (watch UI).
- `app/src/test/.../FakeTvTest.kt`, `FakeSamsungTest.kt` — run pairing and remote sessions against simulated TVs.
